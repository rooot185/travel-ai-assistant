# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Vue 3 and TypeScript on the web. Java for the API and the agent. PostgreSQL for accounts and saved trips.

## Users

Chinese-speaking travelers planning a city trip in mainland China. The project also serves as a portfolio demonstration for an AI application engineering interview.

## Product Purpose

Build a day-by-day plan from dates, budget, preferences and must-visit places. Revise the affected days in natural language while preserving locked stops and the rest of the trip.

## Capabilities and Constraints

Use live model, place search and routing services. Distinguish provider results from budget estimates. Show failed steps with recovery instructions.
